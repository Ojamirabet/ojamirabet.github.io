Herramientas // Red Team & Active Directory
```
nmap RECON
Network Scanner & Port Discovery

El escáner de red más usado en pentesting. Detecta puertos abiertos, versiones de servicios, sistemas operativos y ejecuta scripts NSE de enumeración.

Port Scanning Service Detection OS Fingerprint NSE Scripts
kerbrute RECON
Kerberos User Enumeration & Spray

Enumera usuarios de dominio válidos a través del protocolo Kerberos sin autenticación previa. También permite password spraying sigiloso contra AD.

Active Directory Kerberos User Enum Password Spray
smbclient ENUMERATION
SMB Share Enumeration & Access

Cliente SMB de línea de comandos para listar y acceder a recursos compartidos de red Windows. Permite acceso anónimo, autenticado y transferencia de ficheros.

SMB File Access Anonymous Lateral Movement
dnSpy REVERSE ENGINEERING
.NET Decompiler & Debugger

Descompilador y depurador para binarios .NET y Unity. Permite leer código fuente de ejecutables compilados, editar IL en caliente y extraer secretos hardcodeados.

.NET Reverse Engineering Credential Extraction IL Editing
impacket EXPLOITATION
Windows Protocol Attack Suite

Colección de scripts Python para atacar protocolos Windows: SMB, MSRPC, NTLM, Kerberos, LDAP, MSSQL. La navaja suiza del pentesting en entornos AD.

AS-REP Roasting DCSync NTDS.dit Pass-the-Hash
BloodyAD AD ATTACKS
Active Directory Privilege Escalation

Framework para auditar y abusar de permisos en Active Directory. Permite leer/escribir atributos AD, inyectar registros DNS, modificar ACLs y escalar privilegios sin Bloodhound.

ACL Abuse DNS Injection AD Permissions Privilege Escalation
Responder CREDENTIAL CAPTURE
LLMNR/NBT-NS/MSSQL Credential Capture

Envenenador de protocolos de resolución de nombres (LLMNR, NBT-NS, mDNS) y servidor MSSQL/FTP/HTTP falso para capturar hashes NTLMv2 y credenciales en claro.

LLMNR Poisoning NTLMv2 Capture MitM Cleartext Creds
hashcat CRACKING
Offline Hash Cracking (GPU)

El cracker de contraseñas más rápido del mundo. Soporta +300 tipos de hash y múltiples modos de ataque: diccionario, máscara, combinator y rule-based.

GPU NTLM AS-REP NetNTLMv2 Kerberoasting
evil-winrm POST-EXPLOITATION
Remote Shell via WinRM

Shell interactiva avanzada sobre Windows Remote Management. Soporta Pass-the-Hash, carga de scripts en memoria, bypass de AMSI y upload/download de ficheros.

WinRM Pass-the-Hash AMSI Bypass Post-Exploitation
```
